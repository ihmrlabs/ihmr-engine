# simulations

Named, versioned runs and what came out of them.

Each simulation records its question, inputs, rule set, random seed, outputs, and the exact
commit it ran at. Our research cites these by ID, the way it cites papers.

**A run that produced a boring or unwelcome result gets written up exactly like one that did
not.** Simulations that failed to show what we hoped are often the most useful thing here.
