# apps

Things that run.

| App | What it does |
|:--|:--|
| `ingest/` | Converts source material into clean Markdown, provenance intact |
| `population-simulator/` | Builds synthetic populations to test ideas against |
| `obligation-engine/` | Works out what would be outstanding for a given person or population |
| `capacity-model/` | Models what it would take to actually resolve it |

Each app has its own README explaining how to run it and what it assumes. If a README is
missing or out of date, that is a bug worth reporting.
